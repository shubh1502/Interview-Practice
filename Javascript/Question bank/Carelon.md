6.  What is MCP?
7.  How do we expose an API via MCP?
8.  How do you build a custom MCP tool?
9.  What is the difference between an API and MCP?
10. Can you explain RAG (Retrieval-Augmented Generation)?
11. What is RAG? How do you implement RAG?
12. How do you reduce hallucination in RAG?
13. How do you avoid hallucinations?
14. How do you measure RAG quality?
15. What is the difference between a chatbot, RAG, and an AI agent?
16. Why do we use Chroma DB?
17. What other vector databases have you worked with?
18. Do you know about similarity search in Pinecone?
19. What chunking strategy did you use?
20. What is chunking?
21. What embedding model did you use?
22. How does an embedding model work?
23. How will you protect healthcare data?
